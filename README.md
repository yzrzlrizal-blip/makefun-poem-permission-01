A short original poem about agency — the power to ask and to be given. The program writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt`: a door that waits for a hand that is not the speaker's, an ask made again, softer, and a key turned by someone on the other side.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program is deterministic: every run writes the same poem, byte for byte. It uses only the Python standard library and needs no network.
